State Machine — Depth Diagram
Depth 0 → PIN prompt Depth 1 → PIN check (retry up to 3) Depth 2 → Main menu Depth 3 → Branch: 1=Log 2=Payment 3=Register 4=Stats 0=Exit ── Log Collection (menu 1) ── d3: Collector select (list or phone prompt) d4: List path: material select Phone path: enter phone d5: List: weight | Phone: confirm identity d6: List: price | Phone: material d7: List: confirm | Phone: weight d8: List: END | Phone: price d9: Phone: confirm d10: Phone: END ── Not registered redirect ── d5: "Not found" → 1=Register now d6: first name (phone pre-filled) d7: last name d8: city select d9: confirm registration d10: END (registered) → session ends (agent must redial to log the collection) ── Record Payment (menu 2) ── d3: unpaid collections list (or END if empty) d4: confirm payment d5: END (success) ── Register Collector (menu 3) ── d3: first name d4: last name d5: phone number d6: city select d7: confirm d8: END (success or duplicate) ── My Stats (menu 4) ── d3: END (stats display) Max depth: 10 (Log Collection → phone lookup → not registered → register)
