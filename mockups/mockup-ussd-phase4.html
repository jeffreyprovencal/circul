State Machine — Collector (updated)
d0 → PIN prompt d1 → PIN check (retry up to 3) d2 → Main menu: 1=Drop-off 2=Sell 3=Discovery 4=Stats 0=Exit ── Sell My Material (menu 2) ── d3: Sub-menu (Post / My Listings / My Offers) Post Listing (2→1): d4: material → d5: qty → d6: price → d7: confirm → d8: END My Listings (2→2): d4: listing list → d5: detail (renew/close) → d6: END My Offers (2→3): d4: offer list → d5: detail (accept/decline) → d6: END ── Discovery (menu 3) ── d3: Sub-menu (Browse Buyers / Prices Near Me) Browse Buyers (3→1): d4: material → d5: buyer list → d6: detail → d7: END Prices Near Me (3→2): d4: END (display) ── Unchanged ── 1 = Log Drop-off (existing, no changes) 4 = My Stats (moved from 2, same code) 0 = Exit Max depth: 8 (Post Listing confirm → END)
State Machine — Aggregator (updated)
d0 → PIN prompt d1 → PIN check (retry up to 3) d2 → Main menu: 1=Purchase 2=Pending 3=Marketplace 4=Stats 0=Exit ── Marketplace (menu 3) ── d3: Sub-menu (Browse / Buy Req / Sell / My Offers) Browse Sellers (3→1): d4: material → d5: listings → d6: offer price → d7: confirm → d8: END Post Buy Request (3→2): d4: material → d5: qty → d6: price → d7: confirm → d8: END Sell to Processors (3→3): d4: material → d5: qty → d6: price → d7: confirm → d8: END My Offers (3→4): d4: offer list → d5: detail → d6: END (accept or status) ── Unchanged ── 1 = Log Purchase (existing, no changes) 2 = Pending Drop-offs (existing, no changes) 4 = My Stats (moved from 3, same code) 0 = Exit Max depth: 8 (Browse Sellers → confirm offer → END)
Code Changes Summary
Single file: server.js · No migration needed
All tables (listings, offers, orders, posted_prices) already exist.

Shared pattern — pagination:
All list screens use LIMIT 4 (fetch 3+1). Display up to 3 items. If 4th row exists, show "4. More results →". Selecting "4" re-queries with OFFSET+=3. Page state tracked via depth in the USSD text field. Applied to: seller listings, buyer requests, my listings, my offers, aggregator offers.

Collector handler changes (handleRegisteredUssd):
• Menu reorder: 2=Sell, 3=Discovery, 4=My Stats (was 2)
• Prices Near Me code moves from m[0]==='3' to Discovery sub-handler
• New: handleCollectorSell(m, collector) — sub-menu router
• New: handleCollectorPostListing(m, collector) — INSERT into listings
• New: handleCollectorMyListings(m, collector) — SELECT + renew/close
• New: handleCollectorMyOffers(m, collector) — SELECT + accept/decline + pending_transaction
• New: handleCollectorDiscovery(m, collector) — sub-menu router
• New: handleCollectorBrowseBuyers(m, collector) — SELECT from orders

Aggregator handler changes (handleAggregatorUssd):
• Menu reorder: 3=Marketplace, 4=My Stats (was 3)
• New: handleAggregatorMarketplace(m, aggregator) — sub-menu router
• New: handleAggregatorBrowseSellers(m, aggregator) — SELECT listings + INSERT offer
• New: handleAggregatorPostBuyRequest(m, aggregator) — INSERT into orders
• New: handleAggregatorSellToProcessors(m, aggregator) — INSERT into listings
• New: handleAggregatorMyOffers(m, aggregator) — sent + received, accept

Total: ~12 new functions, 2 modified handlers
