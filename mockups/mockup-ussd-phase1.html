5. PIN Security Improvements
Three-attempt lockout. After 3 wrong PINs in a session, the session ends. No cross-session lockout for now (that's Phase 3).
*920*123#MTN
Wrong PIN — attempt 1
CON Wrong PIN. 2 attempts remaining. Enter your PIN:
FIX — was: "END Invalid PIN. Dial again to retry."
Now stays in session for retries.
→
*920*123#MTN
Wrong PIN — attempt 2
CON Wrong PIN. 1 attempt remaining. Enter your PIN:
→
*920*123#MTN
Wrong PIN — attempt 3 (lockout)
END Too many wrong PINs. Dial again to retry.

7. State Machine — text Input Chain
Every screen maps to a depth in the text field. No server-side session state needed.
Registration flow: text = "" → Screen 1: Welcome (Register/Exit) text = "1" → Screen 2: Enter first name text = "1*Kwame" → Screen 3: Enter last name text = "1*Kwame*Asante" → Screen 4: Select city (NEW) text = "1*Kwame*Asante*1" → Screen 5: Create PIN text = "1*Kwame*Asante*1*1234" → Screen 6: END — Registered! (PIN hashed) Log Drop-off flow: text = "" → Screen 1: Welcome, enter PIN text = "1234" → Screen 2: Main menu text = "1234*1" → Screen 3: Select material text = "1234*1*1" → Screen 4: Enter weight text = "1234*1*1*45" → Screen 5: Select aggregator (NEW) text = "1234*1*1*45*1" → Screen 6: Confirm with price (NEW) text = "1234*1*1*45*1*1" → Screen 7: END — Logged to pending_transactions (FIX) My Stats: text = "1234*2" → END — Monthly/YTD/Earnings/Rating (NEW) Prices Near Me: text = "1234*3" → END — Best prices per material (NEW) PIN retry (within session): text = "wrong" → CON: Wrong PIN, 2 remaining (FIX) text = "wrong*wrong2" → CON: Wrong PIN, 1 remaining text = "wrong*wrong2*wrong3" → END: Too many attempts
