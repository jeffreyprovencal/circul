USSD Phase 5 — Polish: SMS + Ratings

Arkesel SMS provider, transaction event SMS triggers, USSD rating flow nested under My Stats, daily 20-SMS cap per phone.

AArkesel SMS provider — backend only, no UI

Single change in shared/notifications.js. Adds an arkesel case to the existing provider switch. All 9 existing notify() call sites light up automatically. New env vars: NOTIFICATION_PROVIDER=arkesel, ARKESEL_API_KEY, ARKESEL_SENDER_ID.
Daily cap — 20 SMS / phone
In-memory Map keyed by normalized phone number. Resets at midnight UTC. When cap hit: log to console, return {sent:false, reason:'daily-cap'}, never throw. Upgrade to Redis when we have multi-instance.
Failure handling
If Arkesel API call throws or returns non-200, log to console + ntfy.sh, return {sent:false, error}. Never blocks the calling transaction. SMS is best-effort.
Phone normalization
Reuse normalizeGhanaPhone() from server.js so cap is keyed consistently regardless of input format (0244..., +233244..., 233244...).
Provider hot-swap
All call sites unchanged. Switching back to console-only is one env var. No code changes needed for rollback.

BSMS triggers on USSD transaction events

Five new events fire SMS at the moment a USSD action commits. Each adds a single notify() call inside an existing handler — no new endpoints, no schema changes.

Trigger: collector marks payment_status='paid' · Event: PAYMENT_CONFIRMED

Flow logic

depth 0 → list query: SELECT recent unrated transactions WHERE rater=user AND NOT EXISTS (rating by this user for this txn) AND t.created_at > NOW() - INTERVAL '7 days' ORDER BY created_at DESC LIMIT 3 if 0 → END empty state depth 1 → user picks 1/2/3 → store transaction in path → show star screen depth 2 → user picks 1-5 → call createRating() helper → INSERT INTO ratings (...) → END confirmation at any depth: 0 → return to parent menu (CON) invalid → END Invalid option

DClosing the loop — SMS prompts drive rating adoption

Every transaction-logged SMS from Part B includes a tail: "Rate it: dial *XXX# → My Stats → Rate a transaction." Position-agnostic — no hard-coded menu numbers in templates, so reordering the menu later doesn't break SMS copy.
Example — full purchase loop
Circul: AGG-0017 logged 22kg HDPE purchase, GH₵88.00. Rate it: dial *XXX# → My Stats → Rate a transaction.
Collector dials → My Stats → Rate a Transaction → picks the txn → 5★ → done. Rating flow takes 3 screens, ~15 seconds.
