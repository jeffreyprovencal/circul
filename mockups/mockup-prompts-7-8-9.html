Prompt 9 — Name Privacy (Tier-Based)

Names are visible between adjacent tiers only (collector ↔ aggregator, aggregator ↔ processor, etc.). Tiers further apart see ID codes. Collector names are never included in CSV exports.

Privacy rule: Adjacent tiers = real names. Non-adjacent tiers = ID codes (COL-0042, AGG-0017, etc.).
Exception: If two non-adjacent users transact directly (e.g. converter buys from collector), both see each other's names after the first completed transaction.
Export rule: Collector names are ALWAYS replaced with ID codes in CSV exports, even for adjacent aggregators.
